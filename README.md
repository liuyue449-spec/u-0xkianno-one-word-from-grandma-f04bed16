One word, and nothing else: the word Grandma would text about AI. This entry's word is **computor** — the way a grandma actually types "computer": warm, a little baffled, and unmistakably her own spelling. `main.py` writes that single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads it back to prove it landed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
